# Screenshots

These images show real output of the commands named in each title bar, run against a throwaway home folder and the demo vault (`demo/make_demo.py`). The output text was placed into a terminal-style HTML page and captured with a headless browser. Personal paths were replaced with `C:\Users\you`; nothing else was changed. Long output is shortened with `…`.

- `installer-language.png`: `setup/install.py`, first question.
- `installer-dry-run.png`: `setup/install.py --dry-run`, summary step.
- `guard-blocks-command.png`: `_system/command_guard.py` given a `rm -rf` command.
- `session-start.png`: `_system/session_log.py remind`, the session start hook.
- `health-check.png`: `_system/health.py` on the English demo vault.

# Ekran görüntüleri

Bu görüntüler, başlık çubuğunda adı geçen komutların gerçek çıktısıdır; komutlar geçici bir ev klasöründe ve demo vault'ta (`demo/make_demo.py`) çalıştırıldı. Çıktı metni terminal görünümlü bir HTML sayfasına kondu ve ekransız (headless) bir tarayıcıyla görüntüsü alındı. Kişisel yollar `C:\Users\you` ile değiştirildi; başka bir şey değiştirilmedi. Uzun çıktılar `…` ile kısaltıldı.

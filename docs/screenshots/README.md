# Screenshots

The terminal images show real output of the commands named in each title bar, run against a throwaway home folder and a demo vault filled with invented notes. The output text was placed into a terminal-style HTML page and captured with a headless browser. Personal paths were replaced with `C:\Users\you`; nothing else was changed. Long output is shortened with `…`.

- `installer-language.png`: `setup/install.py`, first question.
- `installer-dry-run.png`: `setup/install.py --dry-run`, summary step.
- `guard-blocks-command.png`: `_system/command_guard.py` given a `rm -rf` command.
- `session-start.png`: `_system/session_log.py remind`, the session start hook.
- `health-check.png`: `_system/health.py` on the English demo vault.
- `vault-graph.png`: Obsidian's graph view of a Mindgate vault after about a month of use; note titles are hidden.

# Ekran görüntüleri

Terminal görüntüleri, başlık çubuğunda adı geçen komutların gerçek çıktısıdır; komutlar geçici bir ev klasöründe ve uydurma notlarla doldurulmuş bir demo vault'ta çalıştırıldı. Çıktı metni terminal görünümlü bir HTML sayfasına kondu ve ekransız (headless) bir tarayıcıyla görüntüsü alındı. Kişisel yollar `C:\Users\you` ile değiştirildi; başka bir şey değiştirilmedi. Uzun çıktılar `…` ile kısaltıldı.

`vault-graph.png`, yaklaşık bir aylık kullanımdan sonra bir Mindgate vault'unun Obsidian'daki grafik görünümüdür; not başlıkları gizlidir.
